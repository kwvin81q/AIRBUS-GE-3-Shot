# A300 GE Fan Trim

Upload these files to the root of the GitHub Pages publishing branch. Keep the files together. Open the HTTPS page in Safari, then use Share → Add to Home Screen. The page is available offline once its service worker has finished caching the files.

The worksheet implements the 0°, 123°, and 246° plot from the supplied 72-00-00-05 Method 2, Figure 511. It fits the trial circles numerically. For the printed example, the fit gives 2.04 mils, 26.6° CW and 127.3 g. The figure's hand measurements give 2 mils, 23° CW and 130 g. Use the current controlled AMM to verify the plot and select hardware. The source PDF identifies its effectivity as A310-300 CF6-80C2A2, FED 816–899.
